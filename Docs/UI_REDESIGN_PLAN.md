# Apple Copilot 界面重构

目标：让划词内容立即变成可读的译文，并在原处继续追问。主界面是一张翻译工作台；系统弹窗只提供内容，不再复制宿主的导航栏。

基线评估：Needs work。超大的发送按钮、重复弹窗标题、底部保存入口、历史列表与详情的重复容器，均造成真实操作和阅读摩擦。旧报告的 Excellent 评级没有充分检查这些界面细节。

## 视觉与布局约定

使用系统语义颜色、SF 系统字型与原生导航。下面是用于评估的参考色对，不作为固定颜色覆盖系统设置；实际玻璃材质由系统、背景和辅助功能共同决定，不能把这些参考对比度当成玻璃实测值。

| 角色 | 浅色参考 | 深色参考 | 参考对比度 |
| --- | --- | --- | --- |
| 页面 surface | #FFFFFF | #1C1C1E | — |
| 主正文 content | #1D1D1F | #F5F5F7 | 16.8 / 15.6 |
| 辅助正文 secondary | #595959 | #B8B8BD | 7.0 / 8.6 |
| 操作 accent | #0066CC | #64B5FF | 5.6 / 7.8 |
| 问题 signal | #A32721 | #FF9D95 | 7.3 / 8.5 |

正文使用 `.body`（移动端默认 17pt，Mac 默认 13pt）；原文及用途说明用 `.callout`，分区用 `.headline`，日期与目标语言用 `.caption`。不加入宣传型大标题。文本随系统字号增长。

阅读区域最大宽 760pt。主页面横向留白 20pt，弹窗 16pt；区块之间 24pt，标签与正文之间 8pt。三个平台的追问区均使用**同一个 Liquid Glass 外层容器，发送按钮位于容器内部**。未聚焦、文字为空且未生成时，容器为 Capsule，默认高移动端 56pt、Mac 48pt；聚焦、非空或生成中时展开为圆角 24pt 的 RoundedRectangle，文字位于顶部，容器随内容自然增高。发送使用实心系统强调色圆形，前景随明暗外观适配（浅色白／深色黑），直径移动端 44pt、Mac 36pt，位于容器内部右下角；生成时同一按钮用于停止。输入与按钮不叠加各自的玻璃。iPhone AX5＋深色＋提高对比度已限定实看：黑箭头清楚、圆形不扩大，四行输入内部滚动。

主翻译入口在辅助字号下将目标语言与翻译操作改为竖排，按钮标签保留水平宽度，避免窄横排把标签挤成两行。该入口的 iPhone AX5＋深色＋提高对比度图已实际确认；截图为无原文的禁用状态，其他动作状态仍需按范围验证。

参考图用于容器、展开状态与内嵌操作的布局关系，本轮功能仍为文字追问与发送／停止，不增加附件或语音功能。主应用翻译页、历史详情和系统弹窗复用同一控件。Mac 输入框中的 Escape 只取消焦点，空输入随之折叠，不关闭服务弹窗。

这个方案的特征是“原文—译文—修订对话”连续排版，沿用翻译工作的阅读顺序；不使用通用聊天气泡堆叠或玻璃卡片装饰所有正文。删掉运行页 AI 提示和重复品牌标题，数据去向说明留在设置里。无需额外装饰性动效，滚动保留读者当前位置。

## 依据

- `layout.md › Visual hierarchy`：“Align elements to make them easier to scan”；以标签、间距和对齐建立阅读顺序。
- `buttons.md › Style`：“Use style — not size — to visually distinguish the preferred choice”；发送不再通过尺寸强调。
- `materials.md › Liquid Glass`：“Don’t use Liquid Glass in the content layer”；正文使用正常页面表面，玻璃限于交互控件与系统导航。
- `typography.md › Using system fonts`：“Consider using the built-in text styles”；保留 Dynamic Type。
- `accessibility.md › Mobility`：“Consider spacing between controls as important as size”；追问控件留出明确间隔和外边距。
- `toolbars.md › Best practices`：“Choose items deliberately to avoid overcrowding”；保存作为设置的主要工具栏动作，弹窗操作放在译文旁。

用户明确要求设置嵌入主页面，因此 Mac 设置也作为主导航目的地。系统划词扩展的配置在当前容器内切换，保留返回和未保存编辑确认，不叠加第二张 sheet。

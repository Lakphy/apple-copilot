# 数据与隐私

本文描述当前源码行为，不替模型服务商作数据保留承诺。

## 发往模型服务的数据

用户主动翻译或追问时，请求发送到设置中保存的端点，包含模型 ID、展开后的系统提示词、原文，以及本会话已经完成的问答与当前问题。提示词变量可能包含设备的地区、时区、当前日期和语言识别结果；只有模板引用的变量才会展开进提示词。

API key 放在对应协议的 Authorization 或 x-api-key header。OpenAI Responses 请求设置 `store: false`，但这不代表服务商没有日志、监控或其他保留政策。应用不配置自己的中转服务、账户系统、分析 SDK 或云同步。

打开设置、阅读本地历史或默认启动不触发模型请求。系统翻译入口只接收用户通过宿主提交的选中文本；应用不持续监听所有选区或读取全局剪贴板。复制内容需要用户操作。

## 端点和凭据

- 远程模型端点必须使用 HTTPS；禁止 URL 中的账户密码、查询参数和片段。
- HTTP 仅在用户明确启用时允许 localhost 和回环地址；不允许一般局域网或远程 HTTP。
- 密钥按协议与解析后的完整端点隔离。更换服务后需要重新提供该服务密钥，历史追问不能借用新服务密钥。
- URLSession 使用 ephemeral 配置，关闭持久缓存和 cookie storage，并拒绝重定向。
- 密钥保存在设备 Keychain，加载时不回填可见设置输入框。新密钥草稿在成功保存后清空。
- 任意服务端错误 body 和底层错误描述不会直接显示；界面只使用本地安全说明和错误码。

macOS 主应用使用 Data Protection Keychain；iOS 主应用和扩展通过共享 access group 访问同一组凭据。凭据设置为 `AfterFirstUnlockThisDeviceOnly`，不启用 Keychain 同步。

## 本地文件

| 数据 | 位置 / 内容 |
| --- | --- |
| 设置 | 应用数据目录的 `settings.json`，包含端点、模型、提示词、语言等非密钥配置 |
| 会话 | `Conversations/<UUID>.json`，包含原文、已完成问答、时间和创建时配置快照 |
| 删除标记 | 同目录的 `<UUID>.deleted`，防止迟到的跨进程请求恢复已删除会话 |

iOS 数据位于 App Group 的 `AppleCopilot` 子目录；Mac 使用 Application Support 的 `AppleCopilot` 目录。具体沙盒路径由系统决定。跨进程锁和原子写入防止覆盖其他会话。iOS 文件写入使用文件保护，Mac JSON 文件权限设为 `0600`。

历史文件包含可读文本，没有额外的应用层数据库加密；设备锁定、沙盒及文件保护提供对应系统保护。本地并不意味着一定排除在系统备份之外。系统备份行为取决于平台和用户设置；本项目不声明额外的备份排除策略。

删除历史会删除该会话的 JSON，并保留防止重新写入的空标记。它不删除服务商可能持有的数据。当前界面没有统一的“删除全部数据/所有密钥”操作；修改或卸载应用也不能保证清理 Keychain 条目。

停止或失败的部分回复仅存在当前页面，不写入历史、不纳入下一次模型上下文。只有完整且成功保存的问答才进入历史。

## 富文本与远程图片

Markdown 引擎、字体、公式和 Mermaid 均由本地资源提供，不使用 CDN。HTML 经过 DOMPurify 清理，WebKit 使用非持久网站数据存储与内容安全策略；脚本消息只接受主 frame，并再次验证链接/图片协议和数值。

回复内远程图片不会仅因阅读而下载。用户点击“加载图片”后，原生代码访问图片地址，不带模型 key 或 cookies、不跟随重定向，类型限制为 PNG/JPEG/GIF/WebP，下载大小上限 8 MiB。该图片服务器仍可以看到请求的网络信息。主动打开外部链接后，由系统浏览器或对应应用的规则处理。

## 开发模式与问题报告

Debug `--preview` / `--preview-markdown` 使用内存配置、虚拟凭据和固定文本，不调用远程模型、不读生产 Keychain、不写生产历史。

本机模型 fixture 只绑定回环地址，使用公开测试 key。日志记录协议、消息角色、上下文验证结果和识别到的公开测试句；任意原文、提示词、请求 header 与密钥不写入日志。

提交 Issue 或截图前删除真实 key、私人原文和设备身份信息。敏感问题请使用[安全报告方式](../SECURITY.md)。
